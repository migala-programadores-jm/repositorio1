# Guía de contribución

Gracias por interesarte en colaborar con la comisión de programadores del Proyecto Migala.

## Cómo configurar el entorno local

Actualmente este repositorio contiene principalmente documentación base. Para colaborar:

1. Haz un fork del repositorio.
2. Clona tu fork en tu equipo.
3. Crea una rama nueva a partir de la rama principal.
4. Realiza tus cambios.
5. Revisa ortografía, claridad y coherencia antes de enviar tu propuesta.

Por ahora no hay un proceso de instalación de aplicación porque todavía no existe código ejecutable dentro del repositorio. Cuando eso cambie, esta guía deberá actualizarse.

## Convenciones de contribución

- Escribe documentación en **español claro**.
- Prefiere cambios pequeños, concretos y fáciles de revisar.
- Mantén títulos, listas y estructura consistentes con los documentos existentes.
- Evita mezclar cambios no relacionados en un mismo Pull Request.
- Si propones una decisión importante, explica el problema que resuelve.

## Cómo crear ramas

Usa nombres descriptivos. Ejemplos recomendados:

- `docs/actualiza-readme`
- `docs/agrega-governance`
- `fix/corrige-enlace-roto`
- `feat/define-plantilla-issues`

## Cómo enviar Pull Requests

1. Asegúrate de que tu rama esté actualizada.
2. Haz commits con mensajes claros.
3. Publica la rama en tu fork.
4. Abre un Pull Request hacia el repositorio principal.
5. Describe:
   - qué cambiaste;
   - por qué lo cambiaste;
   - cualquier contexto que ayude a revisar.

## Proceso de revisión

- Toda contribución será revisada por al menos una persona mantenedora o designada para revisión.
- La revisión puede pedir ajustes de contenido, estructura, claridad o alcance.
- El merge se realiza cuando el cambio está suficientemente claro, alineado al proyecto y no tiene observaciones bloqueantes.

## Cómo reportar bugs o proponer features

Si detectas un problema o tienes una idea:

- abre un issue con una descripción clara;
- explica el contexto y el resultado esperado;
- si aplica, propone una solución o alternativa;
- mantén una sola discusión por problema o propuesta.
