# Gobernanza

## Objetivo

Definir cómo se toman decisiones y cómo se cuida la continuidad del proyecto.

## Principios

- apertura en la discusión;
- claridad en la documentación;
- decisiones justificadas;
- responsabilidad compartida;
- prioridad al interés del proyecto y la comunidad.

## Toma de decisiones

Como regla general:

1. Las propuestas se presentan en issues, Pull Requests o discusiones documentadas.
2. Se abre un espacio razonable para comentarios.
3. Las personas mantenedoras buscan consenso.
4. Si no hay consenso, las personas mantenedoras podrán resolver con base en el propósito del proyecto, impacto, mantenimiento y seguridad.

## Mantenedores

Las personas mantenedoras:

- revisan contribuciones;
- ayudan a priorizar trabajo;
- cuidan la coherencia del proyecto;
- moderan procesos comunitarios cuando sea necesario;
- pueden aprobar o rechazar cambios con justificación.

## Cambios a esta gobernanza

Los cambios a este documento deben discutirse y aprobarse mediante Pull Request.
