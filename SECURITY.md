# Política de seguridad

La seguridad es una responsabilidad compartida.

## Cómo reportar una vulnerabilidad

Si detectas una posible vulnerabilidad, por favor:

1. **No la publiques en issues, Pull Requests ni discusiones públicas.**
2. Comparte un reporte privado con la mayor información posible:
   - descripción del problema;
   - impacto potencial;
   - pasos para reproducir;
   - evidencia disponible;
   - posible mitigación, si la tienes.

## Qué esperamos del reporte

Un buen reporte ayuda a responder más rápido. Incluye, cuando sea posible:

- componente afectado;
- severidad estimada;
- alcance;
- condiciones necesarias para explotar el problema.

## Proceso de respuesta

El equipo de mantenimiento intentará:

- confirmar recepción del reporte;
- evaluar impacto y prioridad;
- coordinar una corrección;
- comunicar resolución cuando sea prudente hacerlo.

## Divulgación responsable

Te pedimos no divulgar públicamente una vulnerabilidad hasta que exista una evaluación y, si aplica, una corrección o mitigación razonable.
